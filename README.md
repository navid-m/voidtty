# voidtty

Simple terminal emulator for personal use.

- New horizontal pane: Ctrl+Shift+O
- New vertical pane: Ctrl+Shift+E
- New tab in current pane: Ctrl+Shift+T
- Close tab: Ctrl+Shift+W
